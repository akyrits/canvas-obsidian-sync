# PROTOTYPE — Assignment 6 context experiment

Date: 2026-07-25  
Model: `claude-sonnet-5`  
Generation policy: thinking disabled, effort medium, structured JSON output,
8,000 maximum output tokens  
Safety: paid calls were authorized; the harness never writes the vault

## Question

Does an ICM workspace reduce total token use for Assignment 6 without
weakening the validated Study-mode output?

## Exact input counts

Counts came from Anthropic's token-counting endpoint using the same model and
structured-output configuration.

| Variant | Input tokens | Delta vs current | Pages | Input cost |
| --- | ---: | ---: | ---: | ---: |
| Current | 19,184 | — | 32 | $0.03837 |
| ICM structure only | 20,229 | +1,045 (+5.45%) | 32 | $0.04046 |
| ICM contract | 19,459 | +275 (+1.43%) | 32 | $0.03892 |
| Selective retrieval | 7,952 | -11,232 (-58.55%) | 7 | $0.01590 |

The structure-only variant deliberately adds routing files to the unchanged
production prompt. It isolates an important causal result: folder structure
does not reduce model input unless it changes what evidence is loaded.

## Matched live generation

| Variant | Input | Output | Estimated total cost | Valid | Concepts | Citations |
| --- | ---: | ---: | ---: | --- | ---: | ---: |
| Current | 19,184 | 4,119 | $0.07956 | yes | 5 | 10 |

| Selective retrieval | 7,952 | 3,556 | $0.05146 | yes | 5 | 6 |

All responses ended normally and passed the production Study-mode parser.
Compared with current, selective retrieval reduced input tokens by 58.55% and
measured call cost by 35.32%. The ICM contract's lower output count is not a
reliable saving yet: one nondeterministic generation cannot distinguish a
contract effect from normal model variation.

## Quality finding

This run does **not** pass a production quality gate. All three variants omitted
“Tree Reconstruction from Traversals” as an explicit concept when compared
with the six-concept reference fixture. The selective variant therefore appears
non-inferior to this live baseline, but neither output is the desired product.
The simple concept-name overlap and citation-count metrics are diagnostic only;
they do not prove factual support or citation resolvability.

## Decision

- Reject a wholesale ICM vault migration as a token optimization.
- Keep ICM's useful protocol ideas as a small overlay: a short router, explicit
  stage contract, immutable run manifest, and human-readable evidence packet.
- Put deterministic selective retrieval behind the existing
  `AnalysisEngine.analyze` interface; this is the mechanism that produced the
  material input reduction.
- Do not enable retrieval in production until a multi-assignment evaluation
  passes concept coverage, citation resolution, unsupported-claim, and Study
  mode leakage checks.
- Add per-attempt telemetry before further paid tests so truncations and invalid
  outputs are included rather than only successful commits.

Status: token hypothesis supported; production adoption pending quality eval.
