# Canvas–Obsidian study analysis

This workspace turns one sourced Canvas assignment into validated Study-mode
concept knowledge. It never submits coursework or changes calendar blocks.

## Route by task

| Task | Read | Stop when |
|---|---|---|
| collect or refresh sources | `stages/01_collect/CONTEXT.md` | manifest and hashes exist |
| analyze durable concepts | `stages/02_analyze/CONTEXT.md` | validated JSON exists |
| update the vault | `stages/03_commit/CONTEXT.md` | atomic commit succeeds |
| report status | root `CONTEXT.md`, then stage outputs | current state is reported |

Do not crawl the vault. Load only the exact paths named by the current stage.
